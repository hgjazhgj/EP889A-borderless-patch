# EPSON EP-889A「原寸維持」設定画面の復元パッチ

レーベル印刷のため EW-056AW から EP-889AW に買い替えた際に、それまで使っていたフチなし・原寸維持の印刷方法を引き続き利用したいと考えたことから作成しました。

EW-056AW で写真やはがきを印刷するときは、いつも「フチなし」と「フチなし方法設定－カスタム設定（原寸維持）」を選択していました。私の運用では、周囲に約 3 mm を目安に塗り足しを自分で用意し、倍率 1:1 を保ちながら、用紙の位置が多少ずれても白い余白が出るのを防いでいました。

ところが EP-889AW のドライバーでは、「フチなし方法設定」が見当たらず、「はみ出し量設定」しか調整できませんでした。私の使用環境では、最小の「より少ない」を選ぶと画像自体は拡大されていないように見える一方、印刷領域と実際の用紙位置のずれによって、わずかに白い余白が出てしまいました。

なぜ高価な上位機種で、下位機種にあった機能が使えなくなるの？

ドライバーを解析したところ、フチなし・原寸維持を選んだ際に、画像を拡大・縮小せず、印刷を開始できるアプリケーションに通知する描画領域を用紙外まで広げる処理分岐が、EP-889A 側にも残っていると判断しました。この既存の処理を設定画面から選べるようにし、原寸と塗り足しを活用した印刷方法を取り戻すことが、本パッチの目的です。

## このパッチについて

EPSON EP-889A Series の日本語版 Windows x64 ドライバーで、フチなし設定の「自動拡大／カスタム設定(原寸維持)」選択項目を復元するためのパッチです。適用対象は、下記の変更前 SHA256 と一致するファイルに限ります。

設定画面を復元するもので、初期値は「自動拡大」のままです。「原寸維持」は利用者が選択してください。すべての印刷ジョブで原寸維持を強制するものではなく、描画アルゴリズムも変更しません。

## バイナリファイルの信頼性と自己責任について

原則として、インターネット上で入手したバイナリプログラムを無条件に信頼すべきではありません。本配布物に含まれる DLL も例外ではありません。使用する場合は、利用者自身の判断と責任において使用し、そのリスクを負うものとしてください。

## ファイルの作成方法と変更箇所

### E1TCXFKJ.CFX

対象バージョンの EP-889A ドライバーに含まれる XML 機能定義を使用し、機能 215 の表示属性だけを `S="f"` から `S="t"` に変更しています。

```xml
<!-- 変更前 -->
<F f="215" r="20144" t="0" F="0x0708" S="f">
<!-- 変更後 -->
<F f="215" r="20144" t="0" F="0x0708" S="t">
```

ファイル先頭を 0 としたオフセット `0xA815`（10進数 43029）で、`66 → 74`、つまり ASCII の `f → t` と変更しています。差分はこの 1 バイトだけで、ファイル長、初期値、選択肢、制約規則は変更していません。

### E1TCXFKJ.CFB

EP-889A の既存のコンパイル済み設定キャッシュを使用しています。`fid=215`、リソース ID 20144、フラグ `0x0708` のレコードにある show 属性（IID `0x10`）の DWORD を false から true に変更しています。

```text
オフセット 0x1DA20（10進数 121376）
00 00 00 00 → 01 00 00 00
```

実際の差分は先頭の `00 → 01` の 1 バイトだけです。ファイル長とそれ以外の内容は変更していません。USB、UCB など、ほかのキャッシュファイルも変更していません。

### E1YUIRFKJ.DLL

EP-889A の原版リソース DLL を基に、**RT_DIALOG / 4065 / 日本語 1041（0x0411）** のテンプレートだけを置き換えています。復元用テンプレートは、上記 EW-056A リソース DLL の同じ番号のダイアログから取得しました。

EP のテンプレートは 10 コントロール、EW の対応テンプレートは 14 コントロールです。共通する 10 項目の ID、スタイル、文字列、クラス、X 座標、幅、高さは同じで、ダイアログのスタイル、タイトル、フォントも一致しています。既存のドライバー定義には、4067→`f215=e0`、4068→`f215=e1` の関連付けが残っています。

復元する 4 項目は次のとおりです。

| ID   | コントロール                           |
| ---- | -------------------------------------- |
| 4066 | 「フチなし方法設定」グループボックス   |
| 4067 | 「自動拡大」ラジオボタン               |
| 4068 | 「カスタム設定(原寸維持)」ラジオボタン |
| 4069 | 「はみ出し量」グループボックス         |

テンプレートは 496 バイトから 664 バイトに、ダイアログは 247×130 から 247×190 ダイアログ単位（DLU）になります。既存の 10 項目の Y 座標は、すべて 60 増加します。コードに埋め込まれた復元用テンプレートの SHA256 は次の値です。

```text
e01089b261f9299646a0d91bf28632cbb2c3f18e1e4e70c03abdfea8b34b32ec
```

ビルドコードは Windows の `BeginUpdateResourceW / UpdateResourceW / EndUpdateResourceW` を使用して、新しいファイル内の対象リソースを更新します。元の DLL のコードは実行しません。リソース更新処理で PE ファイルが再配置されるため、ファイル構造には次の変更も生じています。

- リソースセクション、リソースディレクトリ、関連するサイズフィールドが更新され、DLL の長さは 290816 バイトになります。
- `.reloc` の RVA は `0x4B000` から `0x4A000`、ファイルオフセットは `0x47200` から `0x46E00` に移動し、対応する再配置ディレクトリも更新されます。セクション内容は同一です。
- 元の証明書データは更新処理で削除され、Security Directory の 2 フィールドをゼロにしています。
- PE チェックサムを再計算し、`0x4D736` にしています。
- 更新処理で変わったコードページ値は元に戻しています。最終的な全リソース葉エントリの codepage/reserved は原版と同一です。

静的検証では、428 リソースのうち対象テンプレートだけが変更され、ほかの 427 項目の内容は一致しています。`.text/.data/.pdata/.reloc` の元データも一致しています。変更版には有効な純正署名がなく、元の CAT にも一致しません。

## DLL の単独ビルド

[build_dll.py](build_dll.py) を使用します。必要な環境は **64ビット Windows と、64ビット版 Python 3.10 以降**です。上記 SHA256 に一致する EP-889A 原版 `E1YUIRFKJ.DLL` を利用者が用意してください。EW-056A の DLL は不要です。

検証には Python の `assert` を使用しています。検証が省略されないよう、`-O`、`-OO`、または `PYTHONOPTIMIZE` によりアサーションが無効になるモードでは、処理開始前に実行を拒否します。通常の最適化なしの Python で実行してください。

このディレクトリでの実行例：

```powershell
python .\build_dll.py --source "C:\original\E1YUIRFKJ.DLL" --output ".\E1YUIRFKJ.rebuilt.DLL"
```

最初に原版のハッシュを確認します。出力先ディレクトリは事前に存在している必要があり、出力ファイルは未作成である必要があります。スクリプトは原版や既存の出力を上書きしません。生成後、リソース一覧、ほかのリソース内容、リソース以外のセクション内容、PE メタデータを照合します。生成ファイルを配置する際の名前は `E1YUIRFKJ.DLL` にしてください。

既存の変更版 DLL を読み取り専用で検証する場合：

```powershell
python .\build_dll.py --source "C:\original\E1YUIRFKJ.DLL" --verify-only ".\E1YUIRFKJ.DLL"
```

ビルドコードは Python 標準ライブラリと Windows のファイルリソース API のみを使用します。ドライバーを読み込んで実行したり、印刷 API を呼び出したり、ファイルをシステムにインストールしたり、セキュリティ設定を変更したりする処理はありません。

## 手動での置き換えと確認

1. 印刷を開始できるアプリケーション、および印刷設定・プレビューのウィンドウをすべて閉じ、実際に配置されている原ファイルを別途バックアップします。
2. 原ファイルのハッシュを照合し、上表のディレクトリへ変更版を手動でコピーします。Windows に求められた場合は管理者権限を使用します。
3. 印刷を開始できるアプリケーションから EP-889A の印刷設定を開き、フチなしを選択したうえで「はみ出し量設定」を開きます。「カスタム設定(原寸維持)」が表示され、選択できるか確認します。プロセスが古いモジュールを使用している場合は、再起動後に確認してください。
4. 印刷を開始できるアプリケーションに戻り、もう一度設定を開いて選択内容が維持されているか確認します。読み込みに失敗した場合や元に戻す場合は、関連するプログラムを閉じてから、自分で保存した原ファイルを復元します。

この配布物について確認済みなのは、静的なファイル内容と構造です。実行時の DLL 読み込み、コントロールのイベント処理、返される設定、ソフトウェア上のページ領域、実際の用紙外へのはみ出し量は検証が必要です。ファイル検証に合格しただけで印刷結果まで正しいとは判断できません。
